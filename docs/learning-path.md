# 🎯 Complete Data Science Learning Path

A structured 6-month roadmap from beginner to job-ready data scientist.

## Month 1 — Python & Math Foundations
- [ ] Python basics (variables, loops, functions)
- [ ] NumPy fundamentals
- [ ] Pandas DataFrames
- [ ] Descriptive statistics
- **Project:** Analyze a CSV dataset with Pandas

## Month 2 — SQL & Data Wrangling
- [ ] SQL SELECT, WHERE, JOIN
- [ ] Aggregations & GROUP BY
- [ ] Window functions
- [ ] CTEs
- **Project:** PostgreSQL analytics on a public dataset

## Month 3 — EDA & Visualization
- [ ] Matplotlib & Seaborn
- [ ] Plotly interactive charts
- [ ] Missing value handling
- [ ] Outlier detection
- **Project:** End-to-end EDA on Kaggle dataset

## Month 4 — Machine Learning
- [ ] Linear & Logistic Regression
- [ ] Decision Trees & Random Forest
- [ ] Train/test split, cross-validation
- [ ] Metrics (accuracy, precision, recall, F1)
- **Project:** Kaggle Titanic competition

## Month 5 — Advanced ML & Automation
- [ ] XGBoost, LightGBM
- [ ] Feature engineering
- [ ] Selenium web scraping
- [ ] Hyperparameter tuning
- **Project:** Scraper + ML pipeline

## Month 6 — Deployment & Portfolio
- [ ] FastAPI REST APIs
- [ ] Docker basics
- [ ] Deploy to cloud (Vertex AI / Render)
- [ ] Build portfolio site
- **Project:** End-to-end ML app deployed live
