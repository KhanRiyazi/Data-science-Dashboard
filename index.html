photo_camera 📸 Photo & Device Metadata Commands

laptop_mac macOS — Photo EXIF metadata
$ mdls -name kMDItemContentType -name kMDItemPixelHeight -name kMDItemPixelWidth photo.jpg
$ mdls photo.jpg | grep -i "date\|gps\|camera"
$ sips -g all photo.jpg # dimensions, DPI, format
$ exiftool photo.jpg # full EXIF (install: brew install exiftool)
laptop_mac macOS — System & Laptop metadata
$ system_profiler SPHardwareDataType # CPU, RAM, serial
$ sw_vers # macOS version
$ df -h && top -l 1 | head -10 # disk & memory
$ python3 -c "import platform, psutil; print(platform.platform(), psutil.cpu_count())"
desktop_windows Windows — Photo EXIF metadata
PS> Get-Item photo.jpg | Select-Object *
PS> $img = [System.Drawing.Image]::FromFile("photo.jpg"); $img.Width; $img.Height
PS> exiftool photo.jpg # full EXIF (install: choco install exiftool)
desktop_windows Windows — System metadata
PS> Get-ComputerInfo | Select-Object CsName, OsName, OsVersion, CsTotalPhysicalMemory
PS> Get-PSDrive -PSProvider FileSystem # disk space
PS> wmic cpu get name, numberofcores, maxclockspeed
smartphone Mobile — Device metadata
# Android: Settings → About phone → all hardware info
# Android: adb shell getprop ro.product.model ro.build.version.release
# iOS: Settings → General → About → model, iOS version, serial
# Browser: about:gpu → full device & GPU details
# Photo: Tap photo → Info (iOS) or Details (Android) → EXIF
